# 요구사항

## 목적

거래처별 과, 기기, PC 정보를 한 앱에서 빠르게 조회하고 수정하는 안드로이드 오프라인 앱입니다.

기본 구조는 아래와 같습니다.

- 거래처
- 과
- 기기
- PC

## 사용자

- 주 사용자: 아버지 1인
- 사용 환경: 현장 또는 사무실
- 우선순위: 복잡한 기능보다 빠른 조회와 쉬운 수정

## 주요 데이터 구조

### 거래처

- 거래처명
- 메모

### 과

- 과명
- 담당자명
- 연락처
- 메모

### 기기

- 모델명
- IP 주소
- 아이디
- 비밀번호
- 메모

### PC

- 전화번호
- IP 주소
- 아이디
- 비밀번호
- 메모

## MVP 기능

- 거래처 추가 / 수정 / 삭제 / 검색
- 과 추가 / 수정 / 삭제 / 검색
- 기기 추가 / 수정 / 삭제 / 검색
- PC 추가 / 수정 / 삭제 / 검색
- 상세 화면 조회
- 로컬 저장

## UX 기준

- 카드에서 핵심 정보를 바로 읽을 수 있어야 함
- 카드 클릭은 상세, 연필 버튼은 수정
- 메모는 카드 높이를 과도하게 늘리지 않도록 한 줄 말줄임 처리
- 복잡한 설정 없이 바로 사용할 수 있어야 함

## 제외 범위

- 서버 연동
- 다중 사용자 권한
- 클라우드 백업
- 이미지 첨부
- 통계 화면
